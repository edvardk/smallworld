Install

With the official Minecraft Launcher you already have. About five minutes.

  1. Close the Minecraft Launcher if it's open.
  2. Open your Minecraft folder
  3. Unzip the download into that folder. If it asks, merge the versions folder.
  4. In the launcher: Installations, New installation.
  5. Version: fabric-loader-… (near the bottom of the list).
  6. Game directory: Browse, then the smallworld-… folder in your Minecraft folder.
  7. More options, JVM arguments: change -Xmx2G at the start to -Xmx6G
  8. Create, then Play.

Add the mods we can't share

Their makers only allow downloads from their own page. Download each file and put it into the folder shown (the list is also in MISSING-MODS.txt in the zip). Optional ones you can skip.

    Memory: why 6 GB

    Launchers start new installations with 2 GB, too little for these mods. In the official launcher it's the -Xmx number in JVM arguments (step above). In the Modrinth App: the profile's Settings, Java and memory, Memory allocated. Never give it more than half of your computer's memory.

    Using Modrinth App or Prism?

    Use this file instead: it installs everything, including the mods above, by itself.

    Double-click the .mrpack file (or in the app: +, Import from file), Install, then Play. Set the memory as above. Get the Modrinth App

    Play

    Start the new installation, choose Multiplayer: the server is already in your list. Join, and that's it.

    Tip: in game, /view 16 lets you see further while the server runs smoothly.

    Troubleshooting

    Slow, stutters, or "out of memory"

    Give it the memory from step 3 (JVM arguments, -Xmx), or pick a lower tier and install that one too.

    The picture tears, or the mouse lags

    Tearing (a line across the picture when you turn): Options, Video Settings, VSync: ON. Laggy mouse: VSync OFF and Max Framerate at your screen's refresh rate (60, 120, 144…).

    The camera suddenly moves slowly and smoothly

    That's the cinematic camera. This client leaves its key unbound; if you gave it a key, press it again or remove it in Options, Controls, Key Binds.

    A laptop with two graphics cards is slow

    Windows: Settings, System, Display, Graphics: add the launcher's javaw.exe and choose High performance. Plug the laptop in: on battery the graphics card slows down.

    The mouse feels odd

    Options, Controls, Mouse Settings, Raw Input: ON (the default) ignores the system's mouse acceleration. Turn it off if the mouse jumps.

    My keys and mouse sensitivity are back to default

    It's a new game folder. Before the first Play you can copy options.txt from your Minecraft folder into smallworld-… (you keep your keys and lose the tier's graphics settings), or set them once in Options.

    No fabric-loader in the version list

    The zip wasn't unzipped into your Minecraft folder: its versions folder has to land next to the launcher's own. Close the launcher, unzip again, reopen it.

    The code doesn't work

    Each code works once and only for a few minutes. Type /modpack in game for a new one.
